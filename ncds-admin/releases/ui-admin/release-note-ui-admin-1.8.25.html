v1.8.25

2026년 10월 6일

ui-admin 릴리즈 노트 (v1.8.25)​

신규 기능​

  • 드롭다운·달력 패널을 Portal로 띄우는 usePortal 옵션을 추가하였습니다. (DES-SPEC-046, #525)

    • 표 본문(Table horizontalScroll, DataGrid)처럼 overflow가 걸린 컨테이너 안에서 옵션 패널·달력이 잘리던 문제를 피할 수 있습니다. 클리핑은 z-index로는 해소되지 않습니다.
    • React: ComboBox에 usePortal을 추가하였습니다. SelectBox·Dropdown과 달리 상위 Table horizontalScroll의 컨텍스트를 따르지 않으므로, 필요한 위치에 직접 지정해야 합니다.
    • HTML(CDN): SelectBox·Dropdown·ComboBox·DatePicker에 usePortal을 추가하였습니다. Modal을 닫았다 다시 열어도 Portal 패널이 동작합니다.
    • 기본값은 꺼져 있어 기존 화면의 동작과 외형은 바뀌지 않습니다.
    • 패널 위치 계산을 공용 모듈 하나로 합쳐, React와 HTML 버전이 같은 위치에 패널을 띄웁니다.
    • MCP(@ncds/ui-admin-mcp)의 render_to_html에서 usePortal을 경고 없이 사용할 수 있습니다.

  • BreadCrumb에 showHomeIcon prop을 추가하였습니다. (#503)

    • 종전에는 첫 항목이 label 값과 무관하게 항상 홈 아이콘으로 표시되어, 홈이 아닌 경로에서 시작하는 계층(예: 상품 관리 > 상품 목록 > 상품 상세)을 표현할 방법이 없었습니다.
    • showHomeIcon={false}를 넘기면 첫 항목도 나머지 항목과 같이 label 텍스트로 표시됩니다.
    • 기본값은 true이므로 기존 화면의 동작과 외형은 바뀌지 않습니다.
    • 홈 아이콘으로 표시되는 첫 항목에는 label이 aria-label로 부여되어 접근 가능한 이름이 생깁니다. 종전에는 링크 안에 아이콘만 있어 스크린 리더가 읽을 이름이 없었습니다. 첫 항목에 href가 없어 링크가 아닌 경우에는 role="img"가 함께 부여됩니다.
    • BreadCrumb 문서의 인터랙티브 예제에 showHomeIcon 토글을 추가해 두 모드를 비교할 수 있습니다. MCP(@ncds/ui-admin-mcp)에서도 조회할 수 있습니다.

버그 수정​

  • ComboBox에 바깥에서 넣은 value가 선택값 Tag로 표시되지 않던 문제를 수정하였습니다. (#530)
    • 초기값, react-hook-form reset, API 응답처럼 바깥에서 value를 넣어도 폼 값만 있고 Tag가 나오지 않던 문제입니다. 이제 value에 해당하는 옵션이 바로 Tag로 표시됩니다.
    • optionItems가 value보다 늦게 도착해도, 도착하는 순간 Tag가 표시됩니다.
    • 검색으로 optionItems가 걸러져 선택한 항목이 목록에서 빠져도 Tag는 유지됩니다.
    • multiple 모드에서 목록을 클릭해 바꾼 값은 종전과 같이 「선택 완료」를 눌러야 Tag에 반영됩니다. 바깥에서 넣은 값만 바로 반영됩니다.
    • disabled일 때 Tag는 표시하고 Tag의 X(삭제) 버튼은 숨깁니다. 읽기 전용 화면에서 값이 지워지지 않습니다.
    • value에 null을 넘길 수 있습니다. ''·undefined·null이면 Tag가 없습니다. 숫자 0은 값으로 보며, react-hook-form용 hidden input에도 '0'으로 전달됩니다(종전에는 '').
    • Tag의 라벨은 optionItems에서 찾으므로, value의 id가 optionItems에 한 번도 없으면 Tag가 표시되지 않습니다. id는 ===로 비교하므로 숫자 id를 문자열로 넣으면(77과 '77') 같은 값으로 보지 않습니다.
    • ComboBox 문서에 「외부에서 값 설정」 예제와 「비활성화 상태」 선택값 예제를 추가하였습니다.

Breaking Changes​

  • ComboBox 단일 모드의 선택값 Tag가 value를 따릅니다. (#530)

    • value를 넘기지 않거나 onChange에서 value를 갱신하지 않는 화면은, 옵션을 클릭해도 Tag가 표시되지 않습니다. 종전에는 클릭만으로 Tag가 표시되어 폼 값과 화면이 어긋날 수 있었습니다.
    • onChange로 받은 값을 value로 내려주는 controlled 방식으로 사용해 주세요.

  • BreadCrumb 첫 항목의 아이콘 크기 규칙이 다른 선택자로 옮겨졌습니다. (#503)

    • .ncua-breadcrumb__list-item:first-child에 걸려 있던 height: 24px·padding: 4px가 .ncua-breadcrumb__list-item--home으로 이동하였습니다. 크기를 결정하는 기준이 위치(첫 항목)에서 내용(홈 아이콘)으로 바뀐 것으로, 적용되는 값과 기본 동작은 종전과 같습니다.
    • :first-child로 이 영역의 스타일을 덮어쓰던 화면은 해당 선언이 더 이상 적용되지 않습니다. --home 모디파이어로 바꿔 주세요.
    • 홈 아이콘으로 표시되는 첫 항목에 aria-label과(링크가 아닌 경우) role="img" 속성이 추가됩니다. BreadCrumb의 DOM을 선택자로 잡아 스타일을 덮어썼거나 E2E 테스트를 작성한 화면은 확인이 필요합니다.
