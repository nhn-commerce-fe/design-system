v1.8.11

2026년 6월 12일

ui-admin 릴리즈 노트 (v1.8.11)​

신규 기능​

  • 페이지 전체의 작업 컨텍스트(scope)를 전환하는 가로 탭 컴포넌트 ContextTab 을 추가하였습니다.
    • 다중 쇼핑몰 · 다중 계정 · 다중 워크스페이스처럼 여러 컨텍스트를 운영하는 어드민에서, 페이지 데이터 · 설정의 적용 대상을 바꾸는 데 사용합니다.
    • 좌측 ☰ 버튼으로 전체 목록 Dropdown 을, 우측 < > 버튼으로 7개 단위 페이지 넘김(Slider Navigation)을 함께 제공합니다.
    • 각 컨텍스트에 신규 표시(isNew, N 배지)와 임의 텍스트 배지(badgeLabel, pill-outline)를 붙일 수 있으며, 긴 이름은 말줄임 처리되고 마우스를 올리면 전체 이름이 노출됩니다.
    • controlled 컴포넌트로 동작합니다. activeTab 으로 현재 컨텍스트를 지정하고 onTabChange 로 선택을 처리합니다.
    • 콘텐츠 영역만 전환하는 HorizontalTab 과 달리, 컨텍스트(scope) 자체를 바꾸며 데이터 재로드를 동반합니다.
    • 현재 React 전용 컴포넌트로, HTML/CDN(바닐라 JS) 버전은 제공하지 않습니다.

버그 수정​

  • ComboBox · SelectBox(HTML) 단일 선택 모드에서 드롭다운이 열린 채 updateOptions() 호출 시 닫히던 문제 수정 검색·전체 조회·무한 스크롤 등 API 응답을 옵션에 반영하는 흐름에서, 옵션 갱신이 사용자 선택으로 오인되어 "선택 후 닫기" 분기가 실행되던 것이 원인. 선택값이 실제로 변경된 경우에만 통지하도록 수정하고, 내부 이중 갱신도 함께 제거. (React 구현체는 해당 없음)

기능 개선​

  • HTML ComboBox · SelectBox에 드롭다운 열림 상태를 조회하는 isOpen() 메서드 추가
