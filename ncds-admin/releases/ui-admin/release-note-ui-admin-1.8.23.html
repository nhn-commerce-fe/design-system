ui-admin 릴리즈 노트 (v1.8.23)​

버그 수정​

  • Modal의 구분선을 표시할 때 본문 스크롤 영역이 줄어들던 문제를 수정하였습니다. (DES-SPEC-026, #514)
    • Modal.Header·Modal.Actions의 showDivider를 켜면 구분선이 가진 여백(각 16px)이 본문 스크롤 영역 밖에 고정 여백으로 남아, 스크롤할 수 있는 높이가 그만큼 줄어들던 문제입니다. 구분선을 위아래 모두 켜면 32px이 줄어듭니다.
    • 구분선의 여백을 없애고 같은 크기의 여백을 본문(ncua-modal__content) 안쪽으로 옮겼습니다. 여백이 본문과 함께 스크롤되며, 구분선 자체는 종전처럼 본문 밖에 고정됩니다. 겉보기 여백과 구분선 위치는 달라지지 않습니다.
    • prop·마크업·클래스는 종전과 같습니다. showDivider 사용법과 ncua-modal__header-divider·ncua-modal__actions-divider 클래스가 모두 유지되므로 사용처에서 조치할 것이 없습니다.
    • 본문을 form 등으로 감싸 구분선과 본문이 형제 관계가 아닌 경우에도 여백이 적용됩니다.
    • 본문 여백을 자체 CSS로 덮어쓰고 있는 화면은 이번 규칙이 우선하므로 값을 다시 지정해야 할 수 있습니다.
    • 주소 찾기 모달(PostcodeSearchModal)은 검색 영역이 본문 최상단에 붙어야 하므로 위쪽 여백을 적용하지 않습니다.
