v1.8.5

2026년 5월 21일

ui-admin 릴리즈 노트 (v1.8.5)​

신규 기능​

  • ComboBox, SelectBox 에 maxSelection prop 을 추가하였습니다.
    • multiple=true 일 때만 유효한 옵션으로, 최대 선택 가능 개수를 제한합니다.
    • 0 이상의 정수: 제한 활성 → footer 의 "전체 선택" Link 가 미노출됩니다.
      • 0 은 모든 새 선택을 차단합니다.
      • 양수는 도달 후 추가 선택을 무시합니다 (이미 선택된 항목의 해제는 정상 동작).
    • 음수 / 비정수 / null / undefined: 제한 없음 (기존 동작과 동일).
    • React 컴포넌트와 vanilla(<div data-target> 기반) 양쪽에 동일하게 적용됩니다.
  • Tooltip 의 vanilla 빌드에 iconColor 옵션을 추가하였습니다.
    • 기존 React API 와 대칭이 되도록 vanilla 측에도 동일 옵션을 노출하여, 트리거 아이콘의 색상을 직접 지정할 수 있습니다.
    • 타이틀 + 메시지 색상이 gray-500으로 변경 / 굵기 타이틀 700, 메시지 400 으로 변경되었습니다.
  • Notification 에 floating(우측 상단 자동 노출 + LIFO 스택) 동작을 추가하였습니다.
    • 새 알림이 등장하면 우측 상단으로 자동 진입하고, 여러 개가 동시에 떠 있을 때 LIFO(가장 최근 알림이 위) 순으로 스택됩니다.
  • Notification 에 callout 유형을 추가하였습니다.
    • 기존 인라인 알림에 덧붙여, type="callout" 으로 호출박스 스타일의 알림을 렌더할 수 있습니다.
    • 5가지 색상 변형을 지원합니다: neutral (기본), info, warning, error, success.
  • Table 과 DataGrid 에 가로 스크롤을 지원하도록 개선하였습니다.
    • horizontalScroll prop 으로 활성화하면 컬럼이 많을 때 가로 스크롤 기능을 사용할 수 있습니다.
    • minWidth prop 으로 스크롤 발생 최소 너비를 지정할 수 있습니다 (기본값: 1140px).
    • 표 내부의 SelectBox·Dropdown 은 자동으로 Portal 모드로 전환되어 overflow:hidden 경계에 잘리지 않습니다.
    • fixedHeader + horizontalScroll 을 동시에 사용할 수 있으며, 세로 스크롤바는 우측에 고정됩니다.

기능 개선​

  • Tooltip 의 long type 레이아웃 정합성을 보정하였습니다.
    • 닫기 버튼(__close-button) 위치를 top: 2px, right: 2px 단일 값으로 고정 (기존 케이스별 override 정리).
    • 닫기 버튼이 있을 때 panel padding 을 상하 8px · 좌우 12px · 우측 28px 로 통일하여 모든 줄이 닫기 버튼 영역을 침범하지 않도록 조정.
    • __title / __content 의 line-height 를 var(--line-heights-xxs) (16px) 로 동기화.
    • 공백 없이 붙은 긴 텍스트(URL · 한글 무공백 등)가 panel max-width 를 침범하지 않도록 overflow-wrap: anywhere 등을 추가.
    • width: max-content 가 max-width 와 충돌해 wrap 이 일어나지 않던 케이스를 fit-content + min-width: 0 조합으로 정리.

버그 수정​

  • ui-admin 도큐사우루스 문서 페이지의 데모 영역에서 아이콘이 제대로 표시되지 않던 현상을 수정하였습니다.
  • 컴포넌트 전반에 사용되는 z-index 값을 재정렬하여 레이어 충돌을 정돈하였습니다.
  • Table 에서 정의되지 않은 font-weight CSS 변수를 참조하던 부분을 수정하였습니다.

ui-admin 릴리즈 노트 (v1.8.4)​

신규 기능​

  • BlockHeader 컴포넌트를 추가하였습니다.
    • 블록 영역의 헤더로 사용하는 <header> 시맨틱 마크업 기반 컴포넌트입니다.
    • 제목 우측에 툴팁(tooltip), 배지(badge), 액션 버튼(action)을 배치할 수 있습니다.
    • showRequiredNotice prop을 활성화하면 헤더 우측에 * 는 필수 입력 항목입니다. 안내 문구가 표시됩니다.
    • collapsible prop으로 블록 전체를 접기/펼치기 토글할 수 있으며, 접힌 상태에서는 하단 구분선이 자동으로 숨겨집니다.
    • description prop이 있으면 컬럼 레이아웃으로 전환되어 제목 아래에 설명 문구가 표시됩니다.
    • controlStrip 슬롯으로 필터·검색 등 컨트롤 영역을, children으로 탭 컴포넌트를 헤더 하단에 배치할 수 있습니다.
    • showDivider (기본값 true) prop으로 하단 구분선 표시 여부를 제어합니다.
  • BlockHeader 의 BlockHeader.SubTitle 서브 컴포넌트를 추가하였습니다.
    • 블록 바디 내부의 소제목 영역에 사용합니다.
    • size prop으로 'xs' / 'sm' (기본값) / 'middle' 세 가지 크기를 지원합니다.
    • required prop 활성화 시 제목 앞에 필수 마커(*)가 표시됩니다.
    • tooltip, description, error, action prop을 지원합니다.
  • BlockContainer 컴포넌트를 추가하였습니다.
    • <section> 시맨틱 마크업 기반의 블록 레이아웃 컨테이너입니다.
    • Compound Component 구조로 BlockContainer, BlockContainer.Body 두 서브 컴포넌트로 구성됩니다.
  • PageTitle 컴포넌트를 추가하였습니다.
    • 페이지 최상단 제목 영역에 사용하는 <header> 시맨틱 마크업 기반 컴포넌트입니다.
    • variant prop으로 'default' / 'detail' / 'fixed' / 'fixed-detail' 네 가지 레이아웃을 지원합니다.
    • detail 계열 variant에서 onBack prop을 전달하면 제목 좌측에 뒤로가기 버튼이 표시됩니다.
    • breadcrumbItems prop으로 브레드크럼 내비게이션을 표시할 수 있습니다 (fixed 계열에서는 숨김).
    • guideButton, primaryAction, secondaryAction prop으로 제목 영역의 가이드 버튼 및 우측 액션 버튼을 배치할 수 있습니다.

v1.8.3

2026년 5월 8일

ui-admin 릴리즈 노트 (v1.8.3)​

신규 기능​

  • Dropdown 컴포넌트에 config variant 를 추가하였습니다.
    • 드래그 앤 드롭으로 항목 순서를 변경할 수 있습니다 (Atlaskit Pragmatic DnD 통합).
    • Eye 아이콘으로 항목의 표시/숨김을 토글할 수 있습니다.
    • Apply 버튼으로 변경사항을 일괄 적용하며, 취소 시 원본으로 원복됩니다.
    • 키보드 접근성을 보강하였습니다 — ArrowUp/ArrowDown 으로 항목 reorder, ESC 로 닫기 후 트리거에 포커스 복원.
    • role="dialog" / role="menu", aria-pressed, aria-label 등 ARIA 속성을 보강하였습니다.
    • 드롭 인디케이터 라인, 커스텀 드래그 미리보기, 자동 스크롤을 지원합니다.
  • Dropdown 의 vanilla 버전을 추가하였습니다.
    • window.ncua.Dropdown 으로 노출되며 action / config 두 variant 모두 지원합니다.

기능 개선​

  • Tooltip 컴포넌트
    • short 모드의 white-space 를 normal 로 변경하여 긴 텍스트의 줄바꿈을 허용합니다.
  • iOS WebView 등 Web Notifications API 미지원 환경에서 main.min.js 로드 시 Can't find variable: Notification ReferenceError 가 발생하던 문제를 수정하였습니다. 모듈 내부 클래스명을 NcuaNotification 으로 변경하였으며, 외부 노출 API(window.ncua.Notification) 와 NPM export 이름은 그대로 유지되어 사용처 호환성에는 영향이 없습니다.
  • DatePicker / RangeDatePicker 컴포넌트
    • flatpickr 의 disableMobile 기본값을 true 로 강제 적용하여 모바일 환경에서도 PC 디자인이 유지되도록 변경하였습니다.
    • datePickerOptions 로 disableMobile 을 override 할 수 없습니다 — false 를 명시해도 무시됩니다.
  • vanilla FileInputSize / ImageFileInputSize 타입을 React InputBase 와 동일하게 'xs' | 'sm' 두 가지로 좁혔습니다.
    • 종전 'md' / 'lg' 는 입력되어도 React 구현이 의미 있게 처리하지 않아 사실상 noise 였습니다. 디자인 SSoT(DES-SPEC-012 FileInput / DES-SPEC-013 ImageFileInput §5.1·§7.1) 도 두 종류만 정의합니다.
    • 사용자 코드에 'md' 또는 'lg' 를 명시적으로 지정한 경우 타입 에러가 발생하므로 'xs' 또는 'sm' 으로 변경이 필요합니다.

ui-admin 릴리즈 노트 (v1.8.2)​

신규 기능​

  • Tooltip에 zIndex prop을 추가하였습니다.
    • 기본값 2000이며, 모달 등 더 높은 stacking context 위에 띄워야 할 때 값을 지정해 오버라이드할 수 있습니다.
    • --z-index-tooltip 토큰으로 SCSS/CSS 변수화하여 한 곳에서 관리합니다.

기능 개선​

  • Tooltip 컴포넌트
    • 패널을 React Portal로 <body> 하위에 렌더링하도록 전환하여, 부모의 overflow: hidden 및 stacking context 제약에서 자유롭게 동작하도록 개선하였습니다.
    • 패널 최대 너비를 320px(content는 296px)로 제한하고 어절 단위 줄바꿈을 적용하여, 긴 텍스트가 자연스럽게 표시됩니다.
    • 활성(visible) 상태에서만 패널이 마우스 이벤트를 받도록 pointer-events를 분리하여, 숨겨진 패널이 앵커의 hover 이벤트를 가로채던 문제를 해결하였습니다.
    • 포털 분리로 끊겼던 폰트 크기 상속을 __bg에 직접 지정하여 보완하였습니다.
    • hover 시점에 좌표를 동기로 확정하고 다음 프레임에 재보정하여, 웹폰트 로드·레이아웃 안정화로 인한 위치 밀림을 줄였습니다. requestAnimationFrame은 unmount 시 정리하여 누수를 방지합니다.
    • resize/scroll 이벤트에 capture 옵션을 맞춰 내부 스크롤 컨테이너에서도 안정적으로 좌표가 갱신됩니다.

v1.8.0

2026년 4월 17일

ui-admin 릴리즈 노트 (v1.8.0)​

신규 기능​

  • Table 컴포넌트를 추가하였습니다.
    • Compound component 구조로 Table.Header, Body, Row, Cell 등 하위 컴포넌트를 제공합니다.
    • 체크박스 선택, Footer 영역을 지원합니다.
  • DataGrid 컴포넌트를 추가하였습니다.
    • Table 등 원자 컴포넌트를 레이아웃 규칙에 맞게 조합하는 컨테이너 컴포넌트입니다.
    • variant로 search-result, horizontal 두 가지 레이아웃을 지원합니다.
    • 하위 컴포넌트: DataGrid.SearchFilter, Summary, FilterBar, ActionBar(top/bottom), Table, Pagination
    • Child 자동 정렬로 렌더링 순서가 보장되며, selectable 사용 시 하단 ActionBar가 자동 렌더링됩니다.

기능 개선​

  • ButtonGroup, InputBase 컴포넌트에 fullWidth prop을 추가하였습니다.

  • Tooltip 컴포넌트의 tooltipType 기본값을 black에서 white로 변경하였습니다.

  • NumberInput 스타일을 개선하였습니다.

  • 디자인 토큰을 수정하였습니다.

    • color: blue-100, orange-500 hex 값을 수정하였습니다.
    • shadow: primary-color-100 → primary-100으로 네이밍을 수정하였습니다.
    • shadow: 누락되었던 --shadow-xs-focused-3px-primary-100 토큰을 추가하였습니다.
    • spacing: 스케일(XS/S/M/L/XL/XXL)을 재정립하였습니다.
    • font-family: fallback 스택을 추가하였습니다.
    • 비표준 변수(shadow-tooltip, border-radius 등)는 _non-standard-variable.scss로 분리하였습니다.

  • DatePicker 컴포넌트에 portal prop을 추가하였습니다.

    • overflow: auto/scroll/hidden이 적용된 스크롤 컨테이너 안에서 캘린더가 잘리는 문제를 해결합니다.
    • 활성화 시 캘린더가 body에 포탈 마운트되며, 스크롤 시 input 위치를 자동 추적합니다.

ui-admin 릴리즈 노트 (v1.6.3)​

버그 수정​

  • [HTML] comboBox, selectBox, fileInput의 미사용 메서드/코드를 제거하고 내부 모듈 네이밍을 정리하였습니다. (selectBox → unifiedBox)
  • React 컴포넌트의 props/JSDoc을 소스 코드와 동기화하였습니다. (Button, BadgeGroup, Checkbox, ComboBox, DatePicker, Dot, Dropdown, InputBase, NumberInput, Modal, Pagination, Radio, Select, SelectBox, Spinner, Switch, HorizontalTab, VerticalTab, Tag 등)
  • input: __destructive-ico 클래스명 오타를 __destructive-icon으로 수정하였습니다.
  • radio: error 상태에서 hover 시 border-color가 유지되지 않던 스타일을 수정하였습니다.
  • spinner: 텍스트가 없는 경우에도 margin-block-end가 적용되던 문제를 수정하였습니다. (:has(*) 조건으로 변경)
  • tag: 툴팁 위치 관련 미사용 단독 방향 클래스(--top, --bottom, --left, --right, --measuring)를 제거하였습니다.

문서​

  • PasswordInput 컴포넌트 문서를 신규 추가하고 사이드바에 등록하였습니다.
  • 컴포넌트 문서를 소스 코드와 동기화하였습니다. (badge-group, badge, button-group, button, combobox, date-picker, dot, dropdown, empty-state, file-input, horizontal-tab, input, number-input, progress-bar, range-date-picker, selectBox, spinner, switch, tag, vertical-tab)
  • Modal 데모 컨트롤 및 예시 컴포넌트를 업데이트하였습니다.
