v1.8.2

2026년 4월 22일

ui-admin 릴리즈 노트 (v1.8.2)​

신규 기능​

  • Tooltip에 zIndex prop을 추가하였습니다.
    • 기본값 2000이며, 모달 등 더 높은 stacking context 위에 띄워야 할 때 값을 지정해 오버라이드할 수 있습니다.
    • --z-index-tooltip 토큰으로 SCSS/CSS 변수화하여 한 곳에서 관리합니다.

기능 개선​

  • Tooltip 컴포넌트
    • 패널을 React Portal로 <body> 하위에 렌더링하도록 전환하여, 부모의 overflow: hidden 및 stacking context 제약에서 자유롭게 동작하도록 개선하였습니다.
    • 패널 최대 너비를 320px(content는 296px)로 제한하고 어절 단위 줄바꿈을 적용하여, 긴 텍스트가 자연스럽게 표시됩니다.
    • 활성(visible) 상태에서만 패널이 마우스 이벤트를 받도록 pointer-events를 분리하여, 숨겨진 패널이 앵커의 hover 이벤트를 가로채던 문제를 해결하였습니다.
    • 포털 분리로 끊겼던 폰트 크기 상속을 __bg에 직접 지정하여 보완하였습니다.
    • hover 시점에 좌표를 동기로 확정하고 다음 프레임에 재보정하여, 웹폰트 로드·레이아웃 안정화로 인한 위치 밀림을 줄였습니다. requestAnimationFrame은 unmount 시 정리하여 누수를 방지합니다.
    • resize/scroll 이벤트에 capture 옵션을 맞춰 내부 스크롤 컨테이너에서도 안정적으로 좌표가 갱신됩니다.

v1.8.1

2026년 4월 21일

ui-admin 릴리즈 노트 (v1.8.1)​

신규 기능​

  • Table / DataGrid에 Radio 선택 모드를 추가하였습니다.

    • 선택 셀 로직을 정리하여 중복 렌더링을 제거하였습니다.
  • ComboBox 컴포넌트
    • 트레일링 '전체' 버튼이 렌더되지 않던 문제를 수정하였습니다.

v1.8.0

2026년 4월 17일

ui-admin 릴리즈 노트 (v1.8.0)​

신규 기능​

  • Table 컴포넌트를 추가하였습니다.
    • Compound component 구조로 Table.Header, Body, Row, Cell 등 하위 컴포넌트를 제공합니다.
    • 체크박스 선택, Footer 영역을 지원합니다.
  • DataGrid 컴포넌트를 추가하였습니다.
    • Table 등 원자 컴포넌트를 레이아웃 규칙에 맞게 조합하는 컨테이너 컴포넌트입니다.
    • variant로 search-result, horizontal 두 가지 레이아웃을 지원합니다.
    • 하위 컴포넌트: DataGrid.SearchFilter, Summary, FilterBar, ActionBar(top/bottom), Table, Pagination
    • Child 자동 정렬로 렌더링 순서가 보장되며, selectable 사용 시 하단 ActionBar가 자동 렌더링됩니다.

기능 개선​

  • ButtonGroup, InputBase 컴포넌트에 fullWidth prop을 추가하였습니다.

  • Tooltip 컴포넌트의 tooltipType 기본값을 black에서 white로 변경하였습니다.

  • NumberInput 스타일을 개선하였습니다.

  • 디자인 토큰을 수정하였습니다.

    • color: blue-100, orange-500 hex 값을 수정하였습니다.
    • shadow: primary-color-100 → primary-100으로 네이밍을 수정하였습니다.
    • shadow: 누락되었던 --shadow-xs-focused-3px-primary-100 토큰을 추가하였습니다.
    • spacing: 스케일(XS/S/M/L/XL/XXL)을 재정립하였습니다.
    • font-family: fallback 스택을 추가하였습니다.
    • 비표준 변수(shadow-tooltip, border-radius 등)는 _non-standard-variable.scss로 분리하였습니다.

  • DatePicker 컴포넌트에 portal prop을 추가하였습니다.

    • overflow: auto/scroll/hidden이 적용된 스크롤 컨테이너 안에서 캘린더가 잘리는 문제를 해결합니다.
    • 활성화 시 캘린더가 body에 포탈 마운트되며, 스크롤 시 input 위치를 자동 추적합니다.

v1.6.0

2026년 3월 3일

ui-admin 릴리즈 노트 (v1.6.0)​

Breaking Changes​

아이콘 시스템 변경​

아이콘을 문자열 이름('search-lg')으로 전달하던 방식에서, 컴포넌트를 직접 import하여 전달하는 방식으로 변경되었습니다.

변경 전 (v1.5.x)

import { Button } from '@ncds/ui-admin';

<Button label="검색" leadingIcon={{ type: 'icon', icon: 'search-lg' }} />;

변경 후 (v1.6.0)

import { Button } from '@ncds/ui-admin';
import { SearchLg } from '@ncds/ui-admin-icon';

<Button label="검색" leadingIcon={{ type: 'icon', icon: SearchLg }} />;

마이그레이션 방법:

  1. @ncds/ui-admin-icon를 의존성으로 추가합니다.
  2. icon prop에 문자열 대신 import한 컴포넌트를 전달합니다. (예: 'search-lg' → SearchLg, 'arrow-left' → ArrowLeft)

이 변경은 SideSlotType의 icon 필드를 사용하는 모든 컴포넌트에 적용됩니다: Button, ButtonGroup, Dropdown, SelectBox, ComboBox, Modal, Notification, FeaturedIcon, Tag 등.

아이콘 타입 변경​

아이콘을 prop으로 받는 컴포넌트의 타입이 변경되었습니다.

항목변경 전변경 후
SideSlotType의 icon 필드IconName (문자열)SlotIconComponent (컴포넌트)
아이콘 단독 prop (Dropdown, Modal 등)stringSlotIconComponent

SlotIconComponent 타입이 필요하면 @ncds/ui-admin에서 import할 수 있습니다.

import type { SlotIconComponent, SideSlotType } from '@ncds/ui-admin';

신규 기능​

  • SelectBox 컴포넌트에 autoWidth, align prop을 추가하였습니다.
  • SelectBox 옵션에 icon 필드를 추가하였습니다.
