v1.8.12

2026년 6월 17일

ui-admin 릴리즈 노트 (v1.8.12)​

신규 기능​

  • Table / DataGrid 행 드래그 앤 드롭(DnD) 기능을 추가하였습니다.

    • @atlaskit/pragmatic-drag-and-drop 기반으로 구현되었으며, Table에 draggable prop을 전달하면 활성화됩니다.
    • 드래그 핸들 전용(dnd) 및 핸들 + 체크박스 멀티 선택(dnd-checkbox) 두 가지 모드를 지원합니다.
    • 단일·멀티 선택 행의 계단형 드래그 프리뷰(최대 6행, 투명도 그라데이션)를 제공합니다.
    • Table.Body의 onRowDrop(fromId, toId, edge) 콜백으로 드롭 위치를 전달받아 페이지에서 행 순서를 직접 관리합니다.
    • DataGrid.Table에도 draggable prop 패스스루가 추가되어 DataGrid 환경에서도 동일하게 사용할 수 있습니다.

  • HTML/CDN 환경을 위한 window.ncua.Draggable 클래스를 추가하였습니다.

    • Pointer Events API 기반으로 구현되어 React 없이도 Table 행 드래그 앤 드롭을 사용할 수 있습니다.
    • 드래그 핸들, 체크박스 멀티 선택, 이동 버튼(맨위 / 위 / 아래 / 맨아래)을 모두 지원합니다.
    • onDrop / onMove / onSelect 콜백으로 드롭·이동·선택 이벤트를 처리합니다.

v1.8.11

2026년 6월 12일

ui-admin 릴리즈 노트 (v1.8.11)​

신규 기능​

  • 페이지 전체의 작업 컨텍스트(scope)를 전환하는 가로 탭 컴포넌트 ContextTab 을 추가하였습니다.
    • 다중 쇼핑몰 · 다중 계정 · 다중 워크스페이스처럼 여러 컨텍스트를 운영하는 어드민에서, 페이지 데이터 · 설정의 적용 대상을 바꾸는 데 사용합니다.
    • 좌측 ☰ 버튼으로 전체 목록 Dropdown 을, 우측 < > 버튼으로 7개 단위 페이지 넘김(Slider Navigation)을 함께 제공합니다.
    • 각 컨텍스트에 신규 표시(isNew, N 배지)와 임의 텍스트 배지(badgeLabel, pill-outline)를 붙일 수 있으며, 긴 이름은 말줄임 처리되고 마우스를 올리면 전체 이름이 노출됩니다.
    • controlled 컴포넌트로 동작합니다. activeTab 으로 현재 컨텍스트를 지정하고 onTabChange 로 선택을 처리합니다.
    • 콘텐츠 영역만 전환하는 HorizontalTab 과 달리, 컨텍스트(scope) 자체를 바꾸며 데이터 재로드를 동반합니다.
    • 현재 React 전용 컴포넌트로, HTML/CDN(바닐라 JS) 버전은 제공하지 않습니다.

버그 수정​

  • ComboBox · SelectBox(HTML) 단일 선택 모드에서 드롭다운이 열린 채 updateOptions() 호출 시 닫히던 문제 수정 검색·전체 조회·무한 스크롤 등 API 응답을 옵션에 반영하는 흐름에서, 옵션 갱신이 사용자 선택으로 오인되어 "선택 후 닫기" 분기가 실행되던 것이 원인. 선택값이 실제로 변경된 경우에만 통지하도록 수정하고, 내부 이중 갱신도 함께 제거. (React 구현체는 해당 없음)

기능 개선​

  • HTML ComboBox · SelectBox에 드롭다운 열림 상태를 조회하는 isOpen() 메서드 추가

ui-admin 릴리즈 노트 (v1.8.8)​

신규 기능​

  • Table 의 셀에 Tooltip 합성을 지원하도록 개선하였습니다.
    • Table.Cell 에 tooltip prop 을 추가하여 셀 내부에 인라인 Tooltip 을 표시할 수 있습니다.
    • 세로형 레이아웃의 라벨 셀에 Tooltip · Required 표시 등 자식 요소를 함께 합성할 때, 텍스트와 아이콘이 시각적으로 일관되게 정렬되도록 보정하였습니다.
  • ComboBox · SelectBox 의 다중 선택 모드에서 "선택 완료" 버튼 클릭 시 호출되는 onComplete 콜백을 React 컴포넌트에서도 사용할 수 있도록 추가하였습니다.
    • HTML · React 양쪽 모두 콜백 인자로 현재 선택된 값(들)을 전달받도록 시그니처를 (value: string | number | (string | number)[]) => void 로 통일하였습니다.

버그 수정​

  • Table 에서 fixedHeader 와 horizontalScroll 을 동시에 사용할 때 세로 스크롤바가 잘못 표시되던 현상을 수정하였습니다.
    • horizontalScroll 토글 시 세로 스크롤바가 다시 바인딩되지 않아 고아 thumb 가 남던 문제와, 세로 thumb 높이가 실제 스크롤 트랙보다 작게 계산되던 문제를 함께 수정하였습니다.
  • 아이콘 카탈로그 페이지의 사이즈 필터에서 누락되어 있던 12px · 14px 옵션을 복원하였습니다.
    • 문서 페이지 UX 개편 과정에서 빠졌던 두 옵션을 다시 추가하여 기존 7개 사이즈 선택지를 모두 사용할 수 있습니다.
  • ImageFileInput 에서 showFileInput 을 false 로 설정하면 파일 첨부가 동작하지 않던 현상을 수정하였습니다.
    • 숨김 파일 input 이 showFileInput 조건 내부에서만 렌더되어, 이미지 프리뷰 빈 슬롯을 클릭해도 파일 선택 창이 열리지 않던 문제를 수정하였습니다. (기본값 true 사용 시 동작·DOM 변화 없음)
  • ImageFileInput 의 이미지 업로드 슬롯 Tooltip 이 Table 셀 등 overflow 영역 안에서 잘리던 현상을 수정하였습니다.

환경​

  • @ncds/ui-admin-mcp 의 Node.js 요구 버전을 22 이상으로 상향하였습니다.

v1.8.5

2026년 5월 21일

ui-admin 릴리즈 노트 (v1.8.5)​

신규 기능​

  • ComboBox, SelectBox 에 maxSelection prop 을 추가하였습니다.
    • multiple=true 일 때만 유효한 옵션으로, 최대 선택 가능 개수를 제한합니다.
    • 0 이상의 정수: 제한 활성 → footer 의 "전체 선택" Link 가 미노출됩니다.
      • 0 은 모든 새 선택을 차단합니다.
      • 양수는 도달 후 추가 선택을 무시합니다 (이미 선택된 항목의 해제는 정상 동작).
    • 음수 / 비정수 / null / undefined: 제한 없음 (기존 동작과 동일).
    • React 컴포넌트와 vanilla(<div data-target> 기반) 양쪽에 동일하게 적용됩니다.
  • Tooltip 의 vanilla 빌드에 iconColor 옵션을 추가하였습니다.
    • 기존 React API 와 대칭이 되도록 vanilla 측에도 동일 옵션을 노출하여, 트리거 아이콘의 색상을 직접 지정할 수 있습니다.
    • 타이틀 + 메시지 색상이 gray-500으로 변경 / 굵기 타이틀 700, 메시지 400 으로 변경되었습니다.
  • Notification 에 floating(우측 상단 자동 노출 + LIFO 스택) 동작을 추가하였습니다.
    • 새 알림이 등장하면 우측 상단으로 자동 진입하고, 여러 개가 동시에 떠 있을 때 LIFO(가장 최근 알림이 위) 순으로 스택됩니다.
  • Notification 에 callout 유형을 추가하였습니다.
    • 기존 인라인 알림에 덧붙여, type="callout" 으로 호출박스 스타일의 알림을 렌더할 수 있습니다.
    • 5가지 색상 변형을 지원합니다: neutral (기본), info, warning, error, success.
  • Table 과 DataGrid 에 가로 스크롤을 지원하도록 개선하였습니다.
    • horizontalScroll prop 으로 활성화하면 컬럼이 많을 때 가로 스크롤 기능을 사용할 수 있습니다.
    • minWidth prop 으로 스크롤 발생 최소 너비를 지정할 수 있습니다 (기본값: 1140px).
    • 표 내부의 SelectBox·Dropdown 은 자동으로 Portal 모드로 전환되어 overflow:hidden 경계에 잘리지 않습니다.
    • fixedHeader + horizontalScroll 을 동시에 사용할 수 있으며, 세로 스크롤바는 우측에 고정됩니다.

기능 개선​

  • Tooltip 의 long type 레이아웃 정합성을 보정하였습니다.
    • 닫기 버튼(__close-button) 위치를 top: 2px, right: 2px 단일 값으로 고정 (기존 케이스별 override 정리).
    • 닫기 버튼이 있을 때 panel padding 을 상하 8px · 좌우 12px · 우측 28px 로 통일하여 모든 줄이 닫기 버튼 영역을 침범하지 않도록 조정.
    • __title / __content 의 line-height 를 var(--line-heights-xxs) (16px) 로 동기화.
    • 공백 없이 붙은 긴 텍스트(URL · 한글 무공백 등)가 panel max-width 를 침범하지 않도록 overflow-wrap: anywhere 등을 추가.
    • width: max-content 가 max-width 와 충돌해 wrap 이 일어나지 않던 케이스를 fit-content + min-width: 0 조합으로 정리.

버그 수정​

  • ui-admin 도큐사우루스 문서 페이지의 데모 영역에서 아이콘이 제대로 표시되지 않던 현상을 수정하였습니다.
  • 컴포넌트 전반에 사용되는 z-index 값을 재정렬하여 레이어 충돌을 정돈하였습니다.
  • Table 에서 정의되지 않은 font-weight CSS 변수를 참조하던 부분을 수정하였습니다.

    • collapsible prop으로 블록 전체를 접기/펼치기 토글할 수 있으며, 접힌 상태에서는 하단 구분선이 자동으로 숨겨집니다.

  • BlockHeader 의 BlockHeader.SubTitle 서브 컴포넌트를 추가하였습니다.
    • 블록 바디 내부의 소제목 영역에 사용합니다.
    • size prop으로 'xs' / 'sm' (기본값) / 'middle' 세 가지 크기를 지원합니다.
    • required prop 활성화 시 제목 앞에 필수 마커(*)가 표시됩니다.
    • tooltip, description, error, action prop을 지원합니다.
  • BlockContainer 컴포넌트를 추가하였습니다.
    • <section> 시맨틱 마크업 기반의 블록 레이아웃 컨테이너입니다.
    • Compound Component 구조로 BlockContainer, BlockContainer.Body 두 서브 컴포넌트로 구성됩니다.
  • PageTitle 컴포넌트를 추가하였습니다.
    • 페이지 최상단 제목 영역에 사용하는 <header> 시맨틱 마크업 기반 컴포넌트입니다.
    • variant prop으로 'default' / 'detail' / 'fixed' / 'fixed-detail' 네 가지 레이아웃을 지원합니다.
    • detail 계열 variant에서 onBack prop을 전달하면 제목 좌측에 뒤로가기 버튼이 표시됩니다.
    • breadcrumbItems prop으로 브레드크럼 내비게이션을 표시할 수 있습니다 (fixed 계열에서는 숨김).
    • guideButton, primaryAction, secondaryAction prop으로 제목 영역의 가이드 버튼 및 우측 액션 버튼을 배치할 수 있습니다.
