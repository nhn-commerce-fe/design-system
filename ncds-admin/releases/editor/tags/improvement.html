v0.2.1

2026년 4월 27일

Editor 릴리즈 노트 (v0.2.1)​

신규 기능​

  • 반응형 툴바: 컨테이너 너비에 따라 XS / SM / MD / DEFAULT 4단계 툴바 구성을 자동으로 선택합니다.
    • 768 / 992 / 1200px 브레이크포인트 기반
    • 마운트 시점에 컨테이너 너비를 측정해 적절한 구성을 적용합니다.
  • CommerceSans 폰트 지원: 폰트 정의(@font-face 3 weights)와 폰트 패밀리 옵션을 추가하였습니다.

기능 개선​

  • 아이콘 적용 방식 변경: Froala 공식 DefineIcon API로 NCDS 아이콘을 등록하도록 변경하였습니다.
    • Froala 내부 재렌더 시에도 아이콘이 원복되지 않습니다.
    • iframe / non-iframe 모드 모두에서 일관되게 적용됩니다.
    • 누락되어 있던 아이콘 9종을 보강하였습니다 (alignLeft, alignCenter, alignRight, alignJustify, outdent, indent, subscript, paragraphFormat, pastePlain).
  • iframe 스타일 통일: 본문 폰트(나눔고딕), 행간, <p> 여백, NCDS 에디터 CDN CSS를 iframe 내부에 주입하도록 보완하였습니다.
  • 포커스 그림자 보장: fr-focused 클래스를 focus/blur 이벤트에서 수동 관리하여 iframe·non-iframe 모드 모두에서 포커스 시 그림자가 정상적으로 표시됩니다.
  • 콘텐츠 폭 제한·줄바꿈: 패널 320px / content 296px 최대 너비와 한글 어절 단위 줄바꿈(word-break: keep-all)을 적용하였습니다.
  • 툴바 구성 정렬: HTML 버전과 동일한 기본 툴바 구성을 사용하도록 정리하였습니다.
  • 한국어 번역 정리: 번역 파일(languages/ko.ts)의 어색한 문구를 자연스럽게 다듬었으며, 단락 포맷 라벨 Code를 실제 출력 태그와 일치하도록 pre로 변경하였습니다.

보안​

  • HTML 필터링 강화
    • htmlAllowedTags를 명시해 Froala 기본 허용 태그 중 위험 태그를 제외하였습니다.
      • 제거 대상: script, base, bdo, dialog, keygen, menuitem, noscript, queue, title, SVG 계열
      • 반응형 이미지 <picture>는 별도로 허용 목록에 추가하였습니다.
    • htmlRemoveTags를 추가해 위험 태그를 태그·내용 모두 완전 제거합니다.
