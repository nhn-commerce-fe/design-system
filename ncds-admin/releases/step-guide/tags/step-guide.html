v2.0.1

2026년 7월 9일

Step Guide 릴리즈 노트 (v2.0.1)​

단계 진입 제어와 화면 밖 배치 처리를 보강한 패치 릴리즈입니다. v2.0 라인의 연장이므로 CDN 경로는 기존 @ncds/step-guide/2.0/ 그대로이며, 사용처는 별도 URL 변경 없이 최신 동작을 사용할 수 있습니다.

신규 기능​

  • onBeforeChange 콜백 — 각 단계로 넘어가기 직전에 실행할 함수를 지정할 수 있습니다. 강조할 요소를 미리 스크롤하거나 준비하는 등 진입 전 처리에 사용합니다.
  • zIndex 주입 옵션 — 코치마크의 z-index 를 옵션으로 직접 지정할 수 있습니다. (다른 요소에 가려지는 경우 조정)
  • 나중에 나타나는 요소 강조 — 각 단계를 표시하는 시점마다 셀렉터를 다시 조회합니다. 처음에는 없다가 뒤늦게 렌더되는 요소도 강조할 수 있습니다.

개선​

  • 뷰포트 clamp · 4방향 재배치 — 타겟이나 카드가 화면 밖으로 나갈 때, 스크롤 이후의 실제 위치를 기준으로 배치를 다시 결정합니다.
    • 화면을 꽉 채워 어디에도 들어가지 않는 타겟은 카드를 타겟 안쪽 좌상단에 배치합니다.
    • clamp 로 카드가 밀려 화살표가 타겟을 벗어나면 화살표를 숨깁니다.
  • maxScrollTop 을 clientHeight 기준으로 계산하도록 정정했습니다.

문서​

  • Viewport Clamp — 스크롤 기준 배치·타겟 안쪽 배치·화살표 숨김 동작 설명
  • z-index — zIndex 옵션과 stacking context 한계
  • onBeforeChange — 단계 진입 전 콜백 사용법·예시
  • Options — onBeforeChange, zIndex 반영

v2.0.0

2026년 5월 15일

Step Guide 릴리즈 노트 (v2.0.0)​

DES-SPEC-057 Coachmark 사양에 맞춰 NCUA 디자인 시스템 기반으로 전면 리뉴얼하였습니다.

Breaking changes​

  • CSS 클래스 prefix: commerce-ui-* → ncua-coachmark-*
  • NCUA CSS 의존성 추가: NCUA main.min.css 가 페이지에 먼저 로드되어 있어야 시각이 정상 표시됩니다.
  • description, subText 가 최대 2줄로 클램프됩니다 (v1 은 줄 수 제한 없음, 초과 시 말줄임)
  • 버튼·카운터의 시각이 ui-admin 네이티브 클래스(ncua-btn, ncua-carousel-number-group)로 변경
  • CDN 경로가 @ncds/step-guide/2.0/ 으로 분리됩니다. v1 사용처는 @ncds/step-guide/1.0/ 그대로 동작.
  • Step.element 타입: string | null (CSS 선택자). HTMLElement 직접 전달은 지원하지 않습니다.

신규 기능​

  • Step.subText 슬롯 — 본문 아래에 회색 박스 형태의 보조 안내 텍스트
  • 위치 4방향 지원 — position 옵션에 top, left 추가
  • 자동 flip — 툴팁이 화면 밖으로 나가면 반대 방향으로 전환. 양쪽 모두 overflow 면 더 여유 있는 쪽 선택
  • "STEP N" prefix 자동 노출 — 총 step 이 2개 이상이면 타이틀 앞에 자동 추가
  • 기본 버튼 라벨 한국어화 — Prev/Next/Done/Skip → 이전/다음/완료/나중에 하기

개선​

  • 가독성·유지보수성 리팩토링 (메서드 분할, 헬퍼 추출)
  • Vitest + jsdom 기반 테스트 14건 추가

문서​

  • Quick Start — NCUA CSS 사전 요구사항·v2 CDN URL 갱신
  • Options — subText, 4방향 position 반영
  • Position — 4방향 + 자동 flip 동작 설명
