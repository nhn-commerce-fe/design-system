Options

StepGuide는 다양한 옵션을 제공하여 사용자 경험을 커스터마이징할 수 있습니다. 다음은 StepGuide에서 사용할 수 있는 옵션 목록입니다.

사전 요구사항

StepGuide v2 는 NCUA CSS 가 먼저 로드되어 있어야 합니다. 자세한 내용은 Quick Start 참고.

옵션타입설명
elHTMLElementStepGuide가 적용될 HTML 요소입니다.
optionsObjectStepGuide의 설정 옵션을 포함하는 객체입니다.
stepsArray<Step>가이드의 각 단계를 정의하는 배열입니다. 각 단계는 element, title, description 등의 속성을 가집니다.
useAnimationboolean애니메이션 효과를 사용할지 여부를 설정합니다. 기본값은 true입니다.
buttonLabelButtonLabel

버튼의 라벨을 설정합니다. ButtonLabel 타입은 { skip: string; prev: string; next: string; done: string; } 형태입니다. v2 기본값은 한국어 ({ prev: '이전', next: '다음', done: '완료', skip: '나중에 하기' }).

exitOnOverlayClickboolean배경 클릭 시 StepGuide를 종료할지 여부를 설정합니다. 기본값은 true입니다. true일 경우 배경을 클릭하면 StepGuide가 종료되고, false일 경우 다음 단계로 이동합니다.
hideSkipboolean건너뛰기 버튼을 숨길지 여부를 설정합니다. 기본값은 true입니다.
hideStepCountboolean단계 수를 숨길지 여부를 설정합니다. 기본값은 true입니다.
hideStepPrefixboolean

title 앞에 붙는 STEP n 표기를 숨길지 여부를 설정합니다. 기본값은 false. 단계가 1개일 때는 옵션과 무관하게 자동 생략되며, 단계가 2개 이상이면서 선후 관계가 없는 튜토리얼에서 호출자가 명시적으로 끌 때 사용합니다. v2.0.0 추가.

zIndexnumber

코치마크 레이어의 z-index. 미지정 시 z-index 없음(opt-in). CSS 변수 --ncua-coachmark-z-index 로 주입되어, 호스트에 stacking context(헤더·사이드바 등)가 있어 코치마크가 가려질 때 위로 올립니다. 단 z-index 는 el 의 stacking context 안에서만 유효하므로, el 이 자체 stacking context(transform·opacity·position+z-index 등)를 가진 요소면 그 밖의 요소를 넘지 못합니다. 확실히 최상위로 띄우려면 el 을 document.body(또는 stacking context 에 갇히지 않은 최상위 요소)로 두세요.

Instance Methods​

메서드타입설명
onChange(callback: (currentStep: Step, e?: Event) => void) => void스텝 변경 후 호출될 콜백 함수를 설정합니다.
onBeforeChange(callback: (currentStep: Step, index: number) => void | Promise<void>) => void

next/previous 진입 직전에 호출될 콜백을 설정합니다. Promise 를 반환하면 완료를 기다린 뒤 강조를 렌더하므로, 나중에 나타나는 요소를 미리 준비해 깜빡임을 없앨 수 있습니다. goToStep·resize 재렌더에는 발화하지 않습니다. 자세한 예시는 나중에 나타나는 요소 강조하기 참고.

onExit(callback: (e?: Event) => void) => void종료 시 호출될 콜백 함수를 설정합니다.
goToStep(index: number) => void지정한 인덱스의 단계로 이동합니다. (0 ~ steps.length - 1)
nextStep(e: Event) => void다음 단계로 이동합니다.
previousStep(e: Event) => void이전 단계로 이동합니다.
exit(e: Event) => voidStepGuide를 종료합니다.

Step Option​

옵션타입설명
elementstring | null

StepGuide가 적용될 HTML 요소의 CSS 선택자입니다. null인 경우 중앙에 요소가 생성됩니다.

titlestring해당 단계의 제목을 설정합니다. 필수 속성입니다.
descriptionstring해당 단계의 설명을 설정합니다. HTML 허용, 최대 2줄(초과 시 말줄임).
subTextstring

보조 안내 텍스트(회색 박스). HTML 허용, 최대 2줄. 빈 값이면 렌더되지 않습니다. v2.0.0 추가.

position'top' | 'right' | 'bottom' | 'left'

툴팁이 표시될 위치. 기본값은 'bottom'. 지정 방향이 화면 밖으로 나가면 반대 방향으로 자동 flip 됩니다 (v2.0.0+). 자세한 동작은 Position 문서 참고.

customStyleRecord<string, string>요소에 적용할 커스텀 CSS 스타일을 설정합니다. CSS 속성과 값의 객체 형태로 전달합니다.
isFixedboolean요소의 위치를 고정할지 여부를 설정합니다. 선택적 속성입니다.

예시​

다음은 StepGuide 옵션을 사용한 예시입니다:

const guide = stepGuide({
  el: document.body,
  options: {
    steps: [
      {
        element: '#first-step',
        title: '첫 번째 단계',
        description: '이것은 첫 번째 단계입니다.',
      },
    ],
    useAnimation: true,
    exitOnOverlayClick: false,
    hideSkip: false,
    hideStepCount: false,
  },
});

guide.onExit((e) => {
  console.log('종료 완료');
});

이 문서를 통해 StepGuide의 옵션을 이해하고 활용할 수 있습니다.
