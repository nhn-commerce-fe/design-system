PostcodeSearchModal

PostcodeSearchModal은 도로명·지번·건물명으로 주소를 검색하고 결과 중 하나를 선택하는 모달입니다. 주소 입력이 필요한 신청서·배송지 등록 화면에서 사용합니다.

이 컴포넌트는 화면 표현만 담당합니다. 주소 검색 API 호출과 검색어·페이지·결과·선택값 상태는 모두 사용처가 소유하고, 컴포넌트는 검색·페이지 이동·선택 이벤트만 밖으로 알려줍니다.

인터랙티브 예제​

아래 컨트롤로 검색어·결과 건수·오류코드를 바꿔가며 모달의 각 상태를 확인할 수 있습니다. 결과 데이터는 API 대신 데모용 목 데이터로 채워집니다.

searchQuerystring
검색 인풋의 초기 검색어입니다. 비우면 '검색 전' 상태가 됩니다.
totalCountnumber
검색 결과 총 건수입니다. 0이면 결과 없음(EmptyState)이 노출되고, 1 이상이면 Tip 카드가 검색 영역의 한 줄 안내로 바뀝니다.
pageSizenumber
한 페이지에 보여줄 결과 개수입니다. 기획서 기본값은 15입니다.
errorCodeselect
검색어 오류코드입니다. 값이 있으면 인풋이 destructive로 바뀌고 안내 문구가 노출됩니다. E0009~E0013 은 문구가 같아 E0009 하나로 대표합니다.

기본 사용법​

import { PostcodeSearchModal, type PostcodeSearchResult } from '@ncds/ui-admin';
import { useState } from 'react';

function App() {
  const [isOpen, setIsOpen] = useState(false);
  const [searchQuery, setSearchQuery] = useState('');
  const [results, setResults] = useState<PostcodeSearchResult[]>([]);
  const [totalCount, setTotalCount] = useState(0);
  const [currentPage, setCurrentPage] = useState(1);
  const [selectedAddress, setSelectedAddress] = useState<PostcodeSearchResult>();
  const [loading, setLoading] = useState(false);

  // 검색 API 호출은 사용처가 담당합니다.
  const fetchAddresses = async (page: number) => {
    setLoading(true);
    try {
      const response = await searchAddressApi({ keyword: searchQuery, page });
      setResults(response.items);
      setTotalCount(response.totalCount);
      setCurrentPage(page);
    } finally {
      setLoading(false);
    }
  };

  return (
    <>
      <Button label="주소 찾기" onClick={() => setIsOpen(true)} />
      <PostcodeSearchModal
        open={isOpen}
        onClose={() => setIsOpen(false)}
        searchQuery={searchQuery}
        onSearchQueryChange={setSearchQuery}
        onSearch={() => fetchAddresses(1)}
        results={results}
        totalCount={totalCount}
        currentPage={currentPage}
        onPageChange={fetchAddresses}
        loading={loading}
        onSelect={(result) => {
          setSelectedAddress(result);
          setIsOpen(false);
        }}
      />
    </>
  );
}

onSelect(result: PostcodeSearchResult) => void-결과 항목을 선택했을 때 호출됩니다.

PostcodeSearchResult​

PostcodeSearchModal.Tip​

검색어 조합 예시를 안내하는 카드입니다. 결과 목록이 없는 화면(검색 전·오류·결과 없음)에서만 노출되며, 모달이 노출 조건을 스스로 판단해 렌더하므로 보통 직접 쓸 일은 없습니다.

PropTypeDefaultDescription
classNamestring-커스텀 스타일을 위한 className입니다.

상태별 화면​

모달은 아래 조건을 조합해 화면을 스스로 결정합니다.

상황결과 영역Tip 카드
검색 실행 전 (입력 중 포함)아무것도 노출되지 않음노출됨
검색 실행 후 결과 없음EmptyState 안내노출됨
오류코드 있음인풋 오류 상태 + 안내 문구노출됨
결과 있음결과 목록 + 페이지네이션노출되지 않음 (검색 영역에 안내 문구 한 줄만 고정)

오류코드​

errorCode에 따라 검색 인풋 아래 안내 문구가 결정됩니다. 문구는 컴포넌트가 들고 있으므로 사용처가 따로 넘기지 않습니다.

errorCode안내 문구
E0006시도명으로는 검색이 불가합니다.
E0008검색어를 두 글자 이상 입력해주세요.
E0009 ~ E0013검색어를 다시 입력해주세요.

주의사항​

  1. 검색어·페이지·결과·선택값은 모두 사용처가 소유합니다. onSearchQueryChange, onPageChange, onSelect에서 상태를 갱신하지 않으면 화면이 바뀌지 않습니다.
  2. results에는 현재 페이지 분량만 넣습니다. 전체 결과를 넘기면 목록이 한 페이지에 모두 나옵니다.
  3. totalCount는 전체 건수입니다. results.length가 아니라 API가 알려준 총 건수를 넣어야 페이지네이션이 맞습니다.
  4. 오류코드와 검색 결과를 동시에 내려보내지 마세요. 오류가 있으면 목록 대신 안내 문구를 보여주는 화면입니다.
  5. 선택 표시는 컴포넌트가 직접 관리합니다. 사용처는 onSelect로 값을 받기만 하면 되고, 선택값을 다시 내려보낼 필요가 없습니다. 모달을 닫았다 다시 열면 선택이 초기화됩니다.
  6. 검색 API가 비동기라면 loading을 함께 넘기세요. 넘기지 않으면 응답이 오기 전까지 "검색 결과가 없습니다."가 잠깐 노출됩니다.
  7. 화면 너비 768px 이하에서는 페이지네이션이 이전·다음 화살표 형태로 자동 전환됩니다.
  8. "검색 결과가 없습니다." 안내는 검색을 실행한 뒤에만 노출됩니다. 글자를 입력하는 도중에는 뜨지 않고, 검색어를 다시 고치면 사라집니다.
  9. 결과가 있으면 Tip 카드 대신 안내 문구 한 줄만 남고, 검색 인풋과 함께 본문 상단에 고정되어 목록을 스크롤해도 계속 보입니다.
