Tooltip

툴팁은 요소에 대한 추가 정보를 표시하는 작은 팝업 창입니다. 사용자가 요소에 마우스를 올리거나 포커스할 때 나타납니다.

인터랙티브 예제​

아래 UI에서 다양한 속성을 직접 변경하여 Tooltip 컴포넌트의 모습을 확인해보세요.

titlestring
툴팁의 제목
contentstring
툴팁에 표시될 내용
positionselect
툴팁이 표시될 위치
hideArrowboolean
툴팁 화살표 숨김 여부
iconTypeselect
툴팁 아이콘 타입
tooltipTypeselect
툴팁 배경 색상
typeselect
툴팁 타입
iconColorstring
아이콘 색상
iconStyleselect
아이콘 스타일
zIndexnumber
툴팁 패널 z-index

Import​

import { Tooltip } from '@ncds/ui-admin';

기본 사용법​

Props​

PropTypeDefaultDescription
type'short' | 'long''short'툴팁 타입. short: 호버로 표시, 호버아웃으로 숨김 / long: 호버로 표시, X버튼으로만 닫기
position

'top' | 'bottom' | 'left' | 'right' | 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right' | 'auto'

'auto'툴팁의 위치. auto는 공간에 따라 자동 조정
titlestring-툴팁의 제목
contentReact.ReactNode-툴팁에 표시될 내용. 문자열 또는 React 요소(태그 등)를 사용할 수 있습니다.
tooltipType'black' | 'white''white'툴팁 배경 색상
iconType'stroke' | 'fill''stroke'아이콘 스타일
size'sm' | 'md''sm'아이콘 크기
hideArrowbooleanfalse툴팁 화살표 숨김 여부
iconColorstring'var(--gray-300)'아이콘 색상. CSS 변수 또는 색상 값을 사용할 수 있습니다.
iconStyle'help-circle' | 'alert-circle''help-circle'아이콘 스타일. help-circle: 도움말 아이콘 / alert-circle: 경고 아이콘
classNamestring-추가 CSS 클래스명
zIndexnumber2000

툴팁 패널의 z-index. 기본값 2000은 고도몰 기준이며, 모달 등 더 높은 stacking 위에 띄워야 할 때 오버라이드하세요.

툴팁 타입 예제​

Short 타입 (기본)​

Short 타입은 마우스 호버로 표시되고 마우스 아웃으로 숨겨지는 기본 툴팁입니다.

Long 타입​

Long 타입은 마우스 호버로 표시되지만 호버 아웃해도 사라지지 않고, X 버튼으로만 닫히는 툴팁입니다. 긴 텍스트를 표시할 때 사용합니다.

HTML 버전 예제​

JavaScript 버전에서도 동일한 기능을 사용할 수 있습니다:

<!-- Short 타입 (기본) -->
<script>
  const shortTooltip = window.ncua.Tooltip.createShort('Short 툴팁', '마우스 호버로 표시됩니다');
  document.getElementById('container').appendChild(shortTooltip.getElement());
</script>

<!-- Long 타입 -->
<script>
  const longTooltip = window.ncua.Tooltip.createLong(
    'Long 툴팁',
    '마우스 호버로 표시되고, X 버튼으로 닫을 수 있습니다.'
  );
  document.getElementById('container').appendChild(longTooltip.getElement());
</script>

<!-- 옵션으로 생성 -->
<script>
  const customTooltip = window.ncua.Tooltip.create({
    type: 'long',
    tooltipType: 'white',
    iconType: 'fill',
    position: 'auto',
    title: '커스텀 툴팁',
    content: '다양한 옵션을 설정할 수 있습니다.',
  });
  document.getElementById('container').appendChild(customTooltip.getElement());
</script>

z-index 제어​

툴팁 패널은 React Portal로 <body> 하위에 렌더링되어 부모의 overflow: hidden 영향은 받지 않지만, 모달·드롭다운 등 자체 stacking context 위에 띄워야 할 땐 zIndex prop으로 값을 명시해야 합니다.

// 기본: z-index 2000 (고도몰 기준)
<Tooltip content="기본 툴팁" />

// 모달 위에 띄우기
<Tooltip content="모달 위 툴팁" zIndex={9999} />

주의사항​

  1. 툴팁은 viewport를 벗어나지 않도록 자동으로 위치가 조정됩니다.
  2. content 속성은 React.ReactNode 타입으로 문자열뿐만 아니라 React 요소(태그)도 사용할 수 있습니다.
  3. 툴팁은 기본적으로 마우스 호버 시 표시됩니다.
  4. 툴팁 패널은 Portal로 <body> 하위에 렌더링됩니다. 기본 z-index는 2000이며, 상위 stacking context에 가려지면 zIndex prop으로 조절하세요.
