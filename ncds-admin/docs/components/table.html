Table

Table은 어드민 환경에서 데이터를 구조화하여 표시하는 핵심 컴포넌트입니다.
Horizontal Table(목록형)과 Vertical Table(상세형) 두 가지 유형을 제공합니다.

인터랙티브 예제​

아래 UI에서 다양한 속성을 직접 변경하여 Table 컴포넌트의 모습을 확인해보세요.

기본 사용법​

import { Table } from '@ncds/ui-admin';

function App() {
  return (
    <Table type="horizontal">
      <Table.Header>
        <Table.Row>
          <Table.HeaderCell>ID</Table.HeaderCell>
          <Table.HeaderCell>이름</Table.HeaderCell>
          <Table.HeaderCell>상태</Table.HeaderCell>
        </Table.Row>
      </Table.Header>
      <Table.Body>
        <Table.Row>
          <Table.Cell>1</Table.Cell>
          <Table.Cell>상품 A</Table.Cell>
          <Table.Cell>판매중</Table.Cell>
        </Table.Row>
      </Table.Body>
    </Table>
  );
}

Horizontal Scroll (가로 스크롤)​

horizontalScroll 을 켜면 콘텐츠가 부모 너비를 초과할 때 가로 스크롤이 발생한다. minWidth 는 미지정 시 디자인 정책 기본값 1140px 로 적용된다.

디자인 정책 (Dooray 가이드)​

  • 디자인 기준 폭 — 테이블 최소 너비 1140px (14인치 모니터 + LNB 고려). minWidth prop 기본값.
  • 트리거 — 셀별 min-width 합계 ≤ 컨테이너 폭 → 컬럼 자동 확장 / 초과 → 가로 스크롤 자동 발생.
  • 셀 최소 너비 — Table.HeaderCell.minWidth 또는 Table.ColGroup.minWidths 로 글자수 기준 지정.
  • 텍스트 처리 — 최소 너비 도달 시 말줄임 없이 줄바꿈.
  • 헤더 동작 — 세로축 sticky만 적용, 가로 스크롤 시 컬럼과 함께 가로 이동.
  • 서브영역 — Table.Footer·Table.Pagination 은 가로 스크롤 컨테이너 외부에서 항상 고정.

셀별 minWidth 환산표 (글자수 → px)​

var(--font-size-xs)(약 12px) 기준 평균 글자폭.

콘텐츠 유형글자수권장 minWidth
제목·메인이벤트명10자160
제목·메인이벤트명 (정형화)5자80
이름·일자5자80
버튼 (xxs)1개40~60
기타2자32
기타 (복합 요소)—64
<Table horizontalScroll>
  <Table.ColGroup
    widths={['auto', 'auto', 'auto', 'auto']}
    minWidths={[160, 80, 64, 60]}
  />
  <Table.Header>
    <Table.Row>
      <Table.HeaderCell minWidth={160}>상품명</Table.HeaderCell>
      <Table.HeaderCell minWidth={80}>담당자</Table.HeaderCell>
      <Table.HeaderCell minWidth={64}>상태</Table.HeaderCell>
      <Table.HeaderCell minWidth={60}>관리</Table.HeaderCell>
    </Table.Row>
  </Table.Header>
  {/* ... */}
</Table>

horizontalScroll=true 일 때는 내부의 SelectBox·Dropdown 이 자동으로 React Portal 로 렌더되어, 가로/세로 스크롤 wrapper 경계에서 옵션 패널이 잘리지 않는다.

Vertical Table (상세형)​

단일 객체의 속성을 Label-Value 쌍으로 표시하는 상세형 테이블입니다.
필수 항목은 Label 앞에 * 표시를 추가합니다.

*상품명프리미엄 노트북
*카테고리전자기기
*가격₩1,500,000
상태판매중
설명고성능 프로세서와 16GB RAM을 탑재한 프리미엄 노트북입니다.

Empty State (빈 상태)​

데이터가 없을 때 Table.Empty를 사용하여 빈 상태 메시지를 표시합니다.

ID상품명카테고리가격상태
등록된 게시물이 없습니다.
